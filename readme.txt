
Download from the releases tab, then extract the zip file to reveal project files

Run the RunAnki.bat file to initialize the installation of Anki

Wait for the command line to close itself 

Anki should now open with all of the recommended settings

Whenever you want to run Anki again, you MUST open it via the RunAnki.bat file

Run the RunChrome.bat file to initialize Google Chrome

Ask me questions over Discord #CharlesPea
This is a temporary solution to the problem I am trying to solve, and as such, I don't plan on regularly maintaining this project unless requested by users.
The future plans are developing a script that adheres to the user's preferences, so that configurations apply over the user's desired browser and Anki installation, without the need to install portable versions of the softwares.
